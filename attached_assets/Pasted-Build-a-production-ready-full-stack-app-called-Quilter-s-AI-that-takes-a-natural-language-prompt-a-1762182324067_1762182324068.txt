QuiltersAI is a first-of-its-kind tool designed to bridge the gap between creative quilting and technical precision. Whether you are a hobbyist or a professional quilter, this app uses AI to transform your initial concepts into executable patterns, helping you save fabric, time, and creative energy.
​🛠️ Key Features
​Intelligent Pattern Generation: Describe a theme or upload an image, and let the AI propose unique geometric quilt blocks.
​Fabric Estimator: Never over-buy fabric again. Get exact yardage requirements based on your custom designs.

# Tech Stack
- Frontend: React + TypeScript + Vite
- Backend: Python 3.11 + FastAPI
- AI: OpenAI API (text) for interpreting user prompt → structured spec; key via env var OPENAI_API_KEY
